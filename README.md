# Piztu Yang

Xerador de exames de tecnoloxía, matemáticas e física e química (Maxima + LaTeX), con editor de exercicios por bloques e asistencia, se se desexa, por IA.

## Módulos

- [`yang/`](yang) — aplicativo principal Yang (editor de exames).
- [`yang_installer/`](yang_installer) — instalador de Yang para Debian/Ubuntu, Windows e macOS.
