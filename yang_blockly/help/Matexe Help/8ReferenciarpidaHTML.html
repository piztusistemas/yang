 8. Referencia rápida HTML


 

 

 

Etiquetas de estructura

<! ... >

Crea un comentario

<HTML> ... </HTML>

Encierra todo el documento HTML

<HEAD> ... </HEAD>

Encierra el encabezado del documento HTML

<BODY> ... </BODY>

Encierra el cuerpo (texto y etiquetas) del documento HTML

<ISINDEX>

Indica que el documento es un guión de gateway que permite búsquedas

Encabezados y título

<H1> ... </H1>

Encabezados del 1 al 6

<H2> ... </H2>

 

<H3> ... </H3>

 

<H4> ... </H4>

 

<H5> ... </H5>

 

<H6> ... </H6>

 

<TITLE> ... </TITLE>

El título del documento

Párrafos

<P> ... </P>

Párrafo sencillo. </P> es opcional

Vínculos

<A> ... </A>

Crea un vínculo o ancla

HREF="..."

EL URL del documento debe estar vinculado a éste

NAME=...

El nombre del ancla

Listas

<OL> ... </OL>

Lista ordenada (numerada)

<UL> ... </UL>

Lista sin orden (con viñetas)

<MENU> ... </MENU>

Lista de elementos de menú

<DIR> ... </DIR>

Lista de directorio

<LI>

Elemento de la lista

<DL> ... </DL>

Lista de definición o de glosario

<DT>

Término de definición

<DD>

La definición correspondiente de un término de definición

Formato de caracteres

<EM> ... </EM>

Énfasis (normalmente cursivas)

<STRONG> ... </STRONG>

Énfasis mayor (normalmente negritas)

<CODE> ... </CODE>

Muestra de código (normalmente Courier)

<KBD> ... </KBD>

Texto que debe teclearse (normalmente Courier)

<VAR> ... </VAR>

Variable o marcador de posición para algún otro valor

<SAMP> ... </SAMP>

Texto de muestra

<DFN> ... </DFN>

(Propuesta) Definición de un término

<CITE> ... </CITE>

Cita

<B> ... </B>

Texto en negritas

<I> ... </I>

Texto en cursivas

<TT> ... </TT>

Fuente de máquina de escribir

Otros elementos

<HR>

Línea divisoria

<BR>

Salto de línea

<BLOCKQUOTE> ... </BLOCKQUOTE>

Empleada para citas largas

<ADDRESS> ... </ADDRESS>

Firmas o información general acerca del autor de un documento

<FONT> ... </FONT>

Cambio de tamaño de la fuente

SIZE="..."

El tamaño de la fuente, de 1 a 7

<BASEFONT>

Establece el tamaño predeterminado de la fuente para la página actual

SIZE="..."

El tamaño predeterminado de la fuente, de 1 a 7

Imágenes

<IMG>

Insertar una imagen en línea en el documento

ISMAP

Esta imagen es un mapa de imagen donde se puede hacer clic

SRC="..."

El URL de la imagen

ALT="..."

Una cadena de texto que será desplegada en visualizadores que no soportan imágenes

ALIGN="..."

Determina la alineación de la imagen

VSPACE="..."

El espacio entre la imagen y el texto arriba o abajo de ella

HSPACE="..."

El espacio entre la imagen y el texto a su izquierda o derecha

Formularios

<FORM> ... </FORM>

Indica un formulario

ACTION="..."

El URL del guión que procesará esta entrada de formulario.

METHOD="..."

Cómo será enviada la entrada del formulario al guión en el lado del servidor. Los valores posibles son GET y POST.

ENCTYPE="..."

Sólo un valor por el momento: application/x-www-form-urlencoded.

<INPUT>

Un elemento de entrada para un formulario

TYPE="..."

El tipo para este elemento de entrada. Los valores posibles son CHECKBOX, HIDDEN, RADIO, RESET, SUBMIT, TEXT o IMAGE.

NAME="..."

El nombre de este elemento, como pasa al guión de gateway como parte de un par nombre/valor.

VALUE="..."

Para un elemento de texto o escondido, el valor predeterminado; para una casilla de verificación o botón de radio, el valor que debe ser enviado junto con el formulario; para los botones de Reinicio o Envío, el rótulo del botón mismo.

SRC="..."

El archivo fuente de una imagen.

CHECKED

En las casillas de verificación y botones de radio, indica que el elemento está seleccionado.

SIZE="..."

El tamaño, en caracteres, de un elemento de texto.

MAXLENGTH="..."

El número máximo de caracteres que puede ser introducido en un elemento de texto.

ALIGN="..."

Para las imágenes en formularios, determina la forma como se alinearán el texto y la imagen (igual que con la etiqueta <IMG>).

<TEXTAREA>...</TEXTAREA>

Indica un elemento de entrada de texto de varias líneas

NAME="..."

El nombre que se pasará al guión de gateway como parte del par nombre/valor.

ROWS="..."

El número de filas que despliega esta área de texto.

COLS="..."

El número de columnas (caracteres) que despliega esta área de texto.

<SELECT> ... </SELECT>

Crea un menú o lista desplazable de posibles elementos

NAME="..."

El número que se transfiere al guión CGI como parte del par nombre/valor.

SIZE="..."

El número de elementos que son desplegados.

MULTIPLE

Permite selecciones múltiples de la lista.

<OPTION>

Indica un elemento dentro de una etiqueta <SELECT>

SELECTED

Con este atributo incluido, se seleccionará <OPTION> como valor predeterminado en la lista.

VALUE="..."

El valor por enviar si <OPTION> es seleccionada al enviar el formulario.

Tablas

<TABLE> ... </TABLE>

Crea una tabla

BORDER="..."

Indica si la tabla debe dibujarse con o sin recuadro.

<CAPTION> ... </CAPTION>

El título para la tabla

ALIGN="..."

La posición del título. Los valores posibles son TOP y BOTTOM.

<TR> ... </TR>

Fila de tabla

ALIGN="..."

La alineación horizontal de los contenidos de las celdas dentro de esta fila. Los valores posibles son LEFT, RIGHT, CENTER.

VALIGN="..."

La alineación vertical de los contenidos de las celdas dentro de esta fila. Los valores posibles son TOP, MIDDLE, BOTTOM y BASELINE (sólo Nétscape).

<TH> ... </TH>

Celda de encabezado de una tabla

ALIGN="..."

La alineación horizontal del contenido de una celda.

VALIGN="..."

La alinación vertical del contenido de una celda.

ROWSPAN="..."

El número de filas que abarcará esta celda.

COLSPAN="..."

El número de columnas que abarcará esta celda.

NOWRAP

No ajustar de manera automática el contenido de esa celda.

<TD> ... </TD>

Define una celda de datos de una tabla.

ALIGN="..."

La alineación horizontal del contenido de una celda.

VALIGN="..."

La alinación vertical del contenido de una celda.

ROWSPAN="..."

El número de filas que abarcará esta celda.

COLSPAN="..."

El número de columnas que abarcará esta celda.

NOWRAP

No ajustar de manera automática el contenido de esa celda.
